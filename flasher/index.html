This browser can't talk to USB devices. Open the page in Chrome or Edge on a computer. The flasher only works over https. Open the GitHub Pages address.

How to install

  1. Connect the miner's ESP32 USB-C port to this computer. The 12 V supply can stay off.
  2. Pick your board, press Install AxeForge and choose the serial port (usually "USB JTAG/serial debug unit").
  3. If no port shows up, hold BOOT, tap RESET, release BOOT, then try again.
  4. When it's done, join the Wi-Fi called AxeForge-XXXX and open http://192.168.4.1 to set up Wi-Fi and your pool.

Good to know

  • The flasher writes the firmware pieces only, so saved Wi-Fi and pool settings survive. Tick Erase for a clean start.
  • On a Bitaxe, AxeForge replaces AxeOS, and AxeOS's Wi-Fi, pool and clock settings carry over.
  • Later updates don't need this page: upload the board's update file under System → Firmware in the miner's web UI. A file for the wrong board is refused.
  • To go back to stock, flash the stock factory image the same way, or with esptool.py write_flash 0x0 <file>.

Before you flash

Installing replaces the firmware on the miner. To keep a copy of the current one, back it up first:
esptool.py --chip esp32s3 read_flash 0 0x1000000 backup.bin
